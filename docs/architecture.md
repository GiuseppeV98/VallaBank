# NovaBank Architecture

## Goal

NovaBank is a simulated digital banking platform created for educational purposes.

## Applications

- Spring Boot REST API
- React web application
- PostgreSQL database
- Flutter mobile application (future)

## Initial modules

- Authentication
- Users
- Accounts
- Transfers
- Ledger

## Core rule

Every completed monetary transfer must generate balanced ledger entries.

Sum of ledger entries for a transfer = 0.

## Currency

EUR

## Environment

Local development only during the initial phase.
